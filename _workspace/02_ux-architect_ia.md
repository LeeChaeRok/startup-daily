### 전역 내비게이션

| 폭 | 구성 |
|---|---|
| < 1024px | **상단 바(48px)**: 워드마크(→ #/) · 검색 아이콘(→ #/explore, 입력창 포커스) · 테마 아이콘. **하단 탭 바(56px + safe-area)**: 최신 호 · 탐색 · 저장(개수 배지). 소개는 탭에 넣지 않는다(빈도가 낮음). 푸터, AI 고지 한 줄, 처음 방문 카드에서 들어간다. S3에서는 탭 바 대신 **상세 액션 바**를 쓴다(§3-S3). |
| ≥ 1024px | **상단 헤더(64px)**: 워드마크 · 최신 호 · 탐색 · 저장(n) · 소개 · 인라인 검색창(260px) · 테마. 하단 탭 바는 없다. |

[L] "헤더 칩 3줄, 콘텐츠가 화면 1/4 아래" → 상단 바를 1줄 48px로 줄이고, 날짜 칩 행은 없앤다(A9).

### 라우트 규칙 (hooks.js `useRoute` 기준)

| 해시 | 화면 | 파라미터 / 예외 처리 |
|---|---|---|
| `#/` 또는 빈 해시 | S1 | `dates[0]` 호 |
| `#/d/:date` | S2 | `dates`에 없으면 S7("이 날짜에는 호가 없어요" + 가장 가까운 호 링크) |
| `#/s/:id` | S3 | `byId` 실패 시 S7. `from=saved`면 데스크톱 왼쪽 목록과 이전·다음 순서를 저장함 기준으로 바꾼다. 그 외에는 해당 회사의 호 기준 |
| `#/explore` | S4 | `view`(기본 companies), `q`, `sector`(쉼표 다중), `stage`, `region`, `sort` |
| `#/saved` | S5 | `sort`(saved\|date\|sector), `unread=1` |
| `#/about` | S6 | `sec`로 섹션 스크롤. 해시 안에 `#앵커`를 쓸 수 없으므로 쿼리를 쓴다 |
| 그 밖 | S7 | |

- 검색어 입력은 `history.replaceState`로 해시를 갱신한다. `navigate()`를 쓰면 글자마다 히스토리가 쌓인다. 필터 칩을 바꿀 때만 `navigate()`(push)를 쓴다.
- 공유·복사용 URL은 항상 **정규형**(`origin + '/#/s/' + id`, 쿼리 제거)이다.

## 2. 반응형 브레이크포인트

| 구간 | 레이아웃 |
|---|---|
| 375~767 | 1단. 좌우 거터 20px(iOS 엣지 스와이프와 충돌 방지, [B] A3). 본문 16~17px |
| 768~1023 | 1단, 콘텐츠 최대 680px 가운데 정렬. 하단 탭 바 유지 |
| 1024~1279 | **2단 분할**: 왼쪽 목록 340px(sticky, 자체 스크롤) + 오른쪽 본문(최대 680px) |
| ≥ 1280 | **3단**: 왼쪽 목록 360px + 가운데 본문 680px + 오른쪽 레일 260px(sticky) |

분할 뷰에서 오른쪽 내용은 URL이 결정한다. `#/`·`#/d/:date`는 호 개요, `#/s/:id`는 상세. 왼쪽 목록 컴포넌트는 그대로 남아 있으므로 스크롤 위치가 자연히 유지된다([B] #4 "뒤로가기 시 스크롤 복원").

- 공백 안내 문구 규칙. `gap = 오늘(로컬) − dates[0]`(일 단위):
  - `gap = 0`: eyebrow "오늘의 스타트업 · 제n호", 공백 안내 없음
  - `gap = 1`: eyebrow "최신 호 · 제n호", 공백 안내 없음

### 4-1. 첫 방문 (홈 직접 진입)


### 5-1. `src/data/corrections.json` (리드가 이미 생성, data.js가 `s._correction`으로 붙임)

현재 스키마(4건: lilium, wiz, covariant, plenty)는 그대로 쓴다.

```json
"lilium-2026": {
  "status": "운영 중단",          // 화면 라벨 그대로 사용(배지·배너·정정 기록)
  "note": "2025년 2월 운영을 중단하고 …",  // 배너 본문
  "source": "https://avweb.com/…",  // 정정 출처. 외부 링크 금지의 예외(사람이 확인한 링크)
  "checked": "2026-10-22"           // "2026-10-22 확인"
}
```

UI 규칙
- 출처 표기명은 `getDomain(source)`로 만든다(예: avweb.com). 별도 필드가 필요 없다.
- 배너 첫 줄은 `정정 · {checked} 확인`, 본문은 `{status} — {note}`, 마지막 줄은 "아래 본문은 발행 당시({date}) 기준입니다." + 출처 링크.
- 리스트 배지는 `정정 · {status}`. 상세 히어로 메타는 단계 자리에 `{status}`(경고 색 텍스트)를 쓰고, "발행 당시 {_stage}"를 보조로 붙인다.
- **선택적 추가 필드 제안**: `"kind": "shutdown|acquired|restructured|acquihired|public|corrected"`. 단계 필터 그룹과 배지 톤을 정하는 데 쓴다. 없으면 `status` 문자열로 추론한다: `/중단|파산|폐업/` → shutdown, `/인수/` → acquired, 그 외 → 원래 단계 유지, 정보 톤. shutdown·acquired는 단계 그룹 "상장·M&A·종료"로 옮기고 경고 톤을 쓴다. 텍스트 라벨은 어느 경우든 반드시 붙인다.
- 참고 버그: `stageLabel('Post-IPO (재상장 추진)')`과 `stageLabel('Late Stage (Pre-IPO)')`은 `/ipo/` 매칭 때문에 "상장사"가 된다(현재 상장사 8곳으로 집계, 실제는 6곳). 후자는 Growth가 맞다. `pre-ipo`·`late`를 public보다 먼저 검사해야 한다. Lilium은 corrections가 덮어쓴다.
- 데이터 실측(정규화 후): 분야 10개 모두 1곳 이상이고 '기타'는 0곳이다. 단계에 Seed는 0곳이다(초기 그룹 = Series A 13곳).

## 7. 공유

| 위치 | 트리거 | `navigator.share` 페이로드 | 폴백 |
|---|---|---|---|
| S3 상세 (액션 바 / 레일) | (공유) | `title: "{name_ko} — Startup Daily"`, `text: "{tagline} · 제n호(M월 D일)"`, `url: origin + '/#/s/' + id` | `navigator.clipboard.writeText(url)` → 토스트 "링크를 복사했어요" |
| S1/S2 완독 카드, 호 헤더 더보기 | [이 호 공유] | `title: "Startup Daily 제n호"`, `text: "M월 D일 · 로보틱스 3 · 개발자 도구 2 … 10곳"`, `url: '/#/d/{date}'` | 같음 |
| S5 | [링크 목록 복사] | 공유 대신 클립보드 | 아래 2단계 폴백 |

규칙
1. `navigator.share`가 있고 `navigator.canShare?.({url})`가 true면 share를 쓴다. 사용자 제스처 안에서만 호출한다.
2. `AbortError`(사용자 취소)는 아무것도 하지 않는다. 다른 에러는 클립보드 폴백으로 넘어간다.
3. 클립보드도 실패하면(비보안 컨텍스트, 권한 거부) **바텀시트에 읽기 전용 입력창**을 띄운다. URL을 미리 선택해 두고 "길게 눌러 복사하세요" 안내를 붙인다.
4. 데스크톱(공유 시트가 없는 브라우저)은 바로 복사한다. 버튼 라벨은 "링크 복사"로 바꿔 보여 준다(기능 감지 기반).
5. URL에 개인 정보나 읽음 상태를 넣지 않는다.
6. 카카오톡 SDK 공유는 Later(앱 키, 도메인 등록 필요). 해시 URL은 회사별 OG가 불가능하므로 `index.html`에 사이트 공통 OG(`og:title`, `og:description`, `og:image` 1200×630 정적 이미지)를 MVP에서 넣는다.

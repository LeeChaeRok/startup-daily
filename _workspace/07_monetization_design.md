## 3. 상품 설계

### 3-1. "한국에서는" 과금 방식: 건당 크레딧이 아니라 멤버 열람으로 한다

리서치 문서는 "5건 2,900원 크레딧 팩"을 1순위로 제안했다. **현재 구조에서는 맞지 않아 바꾼다.**

- 분석은 **회사 단위**이고 30일간 공개 캐시된다. A가 돈을 내고 만든 분석을 B가 공짜로 본다. 그러면 A가 낸 돈은 생성 원가(70원)가 아니라 "먼저 보는 권리"가 된다. 사용자에게 설명하기 어렵다.
- 대신 다음 둘로 나눈다.

| | 무료 | 멤버 |
|---|---|---|
| 기본 분석(회사 단위, 공용 캐시) | **판정 + 헤드라인 + 한국 플레이어 1곳**까지 | 전체: 해외 유사 제품, 한국 플레이어 전부, 기회·리스크, 출처 |
| 새 분석 요청(아직 아무도 안 만든 회사) | 월 3건(기기 기준) | 무제한(공정 사용 월 30건) |
| **내 관점 분석**(새 상품) | – | 내 회사·아이디어·역할을 입력하면 이 회사와 비교해 "나에게 무슨 의미인지" 분석. 사용자 단위라 캐시하지 않는다. 진짜 건당 원가가 드는 기능 |
| 내보내기 | – | 링크·PDF(AI 생성 표시와 생성일 포함) |

**대안(보류): 크레딧 팩.** "내 관점 분석"만 따로 건당 판매하는 방식이다. 멤버십 전환이 낮을 때 추가 옵션으로 연다.

### 3-2. 개인 멤버십: "Startup Daily 멤버"

- **가격(제안):**
  - 월 4,900원 / 연 49,000원(약 2개월 무료)
  - 출시 기념 첫 3개월 월 2,900원(창립 멤버)
  - 근거: 롱블랙 5,900원이 국내 개인 지식 구독의 상한 기준이다. 해외 스타트업 중심이라 대중성이 더 낮다.
- **포함:**
  1. "한국에서는" 전체 열람 + 새 분석 무제한(공정 사용)
  2. 내 관점 분석 월 10건
  3. **아카이브 전체**(30일이 지난 호)
  4. 섹터·회사 팔로우 알림(후속 투자 소식)
  5. 탐색 표 CSV 내보내기
  6. 주간 레터의 멤버판(이번 주 한국 기회 Top 3)
- **무료로 남길 것:** 오늘 호 전체, 최근 30일 아카이브, 회사 상세 전 섹션, 저장, 검색. 습관과 공유가 막히면 유입이 끊긴다.
- **체험:** 결제 없이 7일 체험. 자동 결제로 넘어가지 않는다. 전자상거래법 다크패턴 규제를 피하고, 해지 마찰을 없앤다.

### 3-3. B2B: 섹터 스카우팅 노트

- 형태: 월 1회, 섹터별(예: 기후테크, 헬스케어 AI, 핀테크 인프라) 해외 초기 스타트업 10~15곳을 정리한다. 각 회사에 대해 "한국에서는" 분석, 비교표, 출처를 붙인다. PDF와 웹 링크로 제공한다.
- 가격(제안):
  - 사내 열람 월 30만 원 / 협력사 전달 포함 월 60만 원(VAT 별도, 세금계산서)
  - 단건 리포트 50만 원
  - 근거: 바이라인 네트워크 월 50만~100만 원, 혁신의숲 Pro 월 30만 원
- 생산 방식: 기존 파이프라인을 섹터 필터로 돌린다. 리포트 1건 원가는 1~2달러 수준이고, **사람 검수 2~3시간**이 핵심 비용이다.
- 영업: 샘플 리포트 3종을 무료로 공개하고, CVC·액셀러레이터 10곳에 직접 연락한다. 첫 1~3곳은 할인 대신 피드백을 받는다.

### 3-4. 스폰서 (후순위)

- 주간 레터 구독 5천 명 이상이고 오픈율 40% 이상일 때 연다.
- 레터 1칸 + 오늘 호 하단 1칸. "스폰서" 표기를 본문 앞에 둔다(추천·보증 심사지침).
- **소개 회사 선정과는 완전히 분리한다.** 돈을 받고 회사를 소개하지 않는다. 이 원칙을 소개 페이지에 공개한다.

### 3-5. 하지 않는 것

- 제휴 링크가 있는 회사를 "오늘의 스타트업"에 넣지 않는다(선정 편향).
- 유료 투자 Q&A 커뮤니티(오픈채팅·디스코드)를 운영하지 않는다. 쌍방향 유료 채널은 투자자문업 등록 대상이 될 수 있다.
- "투자 매력", "지금이 매수 기회" 같은 문구를 쓰지 않는다. "한국 기회"는 **사업 기회(진출·경쟁·파트너십)**로만 쓴다.
- 해외 결제대행(Paddle, Lemon Squeezy)으로 소액 원화 결제를 받지 않는다. 건당 50센트 고정 수수료 때문에 실효 수수료가 25%를 넘는다.

## 4. 단계별 실행 (Phase)

### Phase 0. 측정: 지금 바로, 고정비 0원

목표: 돈을 받기 전에 지불 의사를 숫자로 본다.

1. **이메일 주간 레터 가입**: 오늘 호 하단, 상세 하단, 저장 화면에 둔다.
   - 발송은 메일리를 쓴다(무료 플랜, 나중에 유료 멤버십으로 바로 전환 가능).
   - 매주 월요일, 지난주 5곳 + 한국 기회 1개를 보낸다.
2. **페이크 도어**: "한국에서는" 무료 한도(월 3건)에 걸리거나 "전체 보기"를 누르면 멤버십 소개 시트를 띄운다.
   - 시트 내용: "멤버십 준비 중 · 월 4,900원 예정 · 출시 알림 받기(이메일)".
   - 클릭률과 이메일 수를 잰다.
   - 지금은 잠그지 않는다. 시트를 닫으면 전체를 그대로 보여준다. 측정만 한다.
3. **분석 도구**: Vercel Web Analytics의 커스텀 이벤트로 잰다.
   - 이벤트: 상세 진입, 한국 분석 요청·완료, 페이크 도어 노출·클릭, 레터 가입.
4. **보관 정책 변경**: `RETAIN_ISSUES` 제한을 없앤다. 대신 오래된 호는 별도 JSON으로 분리해 번들 크기를 지킨다.
5. **AI 고지·문구 가이드**: 소개 페이지에 "AI가 공개 자료로 작성 · 투자 조언 아님 · 회사 선정에 대가 없음"을 넣는다. 공유 카드에도 AI 생성 표시를 넣는다.

### Phase 1. 개인 멤버십 출시

열리는 조건: 레터 구독 300명 이상 **그리고** 페이크 도어 이메일 50명 이상(§6).

1. **로그인**: 이메일 매직링크(Resend). 카카오 로그인은 2차로 둔다.
2. **결제**: 사업자등록(간이과세) → 포트원 + PG(가입비 면제 패키지). 정기결제(빌링)를 쓴다.
   - 더 빨리 검증하는 대안: 메일리 유료 멤버십으로 받는다. 수수료 20%이지만 사업자·PG가 필요 없다. 이 경우 웹앱은 메일리 결제 여부를 조회해 권한을 준다. 연동 가능 여부는 확인이 필요하다.
3. **잠금 적용**: §3-1의 무료/멤버 경계를 그대로 적용한다. 잠긴 데이터는 API에서만 내려보낸다.
4. 7일 무료 체험, 창립 멤버 가격.

### Phase 2. B2B 노트

열리는 조건: 정정 로그와 정확성 지표(링크 생존율, 정정 건수)를 공개할 수 있을 때. 독자 수와는 무관하게 병행한다.

1. 샘플 리포트 3종(공개)과 소개 페이지 `#/for-teams`를 만든다.
2. 첫 고객은 수작업으로 받는다. 세금계산서를 발행하고 PDF를 메일로 보낸다. 시스템화는 3곳 이상 고객이 생긴 다음에 한다.

### Phase 3. 스폰서

열리는 조건: 레터 5천 명 이상, 오픈율 40% 이상.

## 6. 단계 전환 지표 (Gate)

| 다음 단계 | 조건 | 측정 |
|---|---|---|
| Phase 0 → 1 | 레터 구독 300명 이상, 페이크 도어 이메일 50명 이상, 페이크 도어 클릭률(시트 노출 대비) 5% 이상 | Vercel Analytics, 메일리 |
| 1 유지 판단(3개월) | 유료 30명 이상, 월 해지율 10% 이하 | 결제 대시보드 |
| Phase 2 착수 | 샘플 리포트 3종 완료, 링크 생존율 95% 이상, 정정 로그 공개 | 파이프라인 로그 |
| Phase 3 | 레터 5천 명 이상, 오픈율 40% 이상 | 메일리 |

**숫자 감각:** 무료 1만 명 × 전환율 1% = 유료 100명 × 4,900원 = 월 49만 원(수수료 전)이다. 개인 멤버십만으로는 용돈 수준이다. **의미 있는 매출은 B2B 2~3곳(월 60만~150만 원)에서 먼저 나올 가능성이 높다.** 멤버십은 매출보다 "제품이 가치 있다는 신호"로 본다.

## 7. 기술 설계 (Phase 1 기준)

```
브라우저 ─ 무료 데이터: 번들(최근 30일 호, 무료 분석 미리보기만)
        └ /api/me            로그인 상태·멤버 여부·남은 횟수
        └ /api/korea-lens    무료: 미리보기 필드만 / 멤버: 전체 (캐시: 공용 원본 + 응답 단계에서 잘라냄)
        └ /api/lens-personal 멤버 전용, 캐시 없음
        └ /api/archive?date= 30일 지난 호(멤버)
        └ /api/auth/*        매직링크(Resend)
        └ /api/billing/*     포트원 웹훅 → 멤버 상태 갱신
저장소: Upstash Redis(Vercel Marketplace)
  - user:{email} → { plan, until, trial_until }
  - quota:{user|device}:{yyyymm} → 사용 횟수   (지금의 메모리 리밋 대체)
  - lens:{id} → 분석 원본(엣지 캐시 대신 원본 저장)
```

- 핵심 변경: `korea-lens.json`의 전체 분석은 번들에서 빼고 미리보기 필드만 남긴다. 전체 본문은 API가 권한을 확인한 뒤 내려준다.
- 공용 캐시는 유지한다. 원본은 Redis에 한 번만 생성해 두고, 응답할 때 권한에 따라 필드를 잘라낸다. 생성 원가는 회사당 1회로 유지된다.
- Phase 0에는 Redis가 필요 없다. 페이크 도어 이메일은 메일리 별도 그룹으로 모은다. 무료 횟수는 localStorage에 표시용으로 기록하고, 서버의 기존 IP 리밋을 유지한다.
- `vercel.json`은 만들지 않는다. 함수별 설정은 기존처럼 파일 안 `export const config`로 한다.

## 9. 사용자 결정이 필요한 것

1. **사업자등록 의향.** Phase 1을 직접 결제로 할지(간이과세 등록 + 포트원), 메일리 유료 멤버십으로 우회할지 정해야 한다.
2. **B2B 영업을 직접 할 의향.** 직접 하지 않는다면 Phase 2를 빼고, 샘플 리포트만 공개한다.
3. **Phase 0 착수 여부.** 레터 가입 카드, 페이크 도어 시트, 분석 이벤트, 보관 정책 변경, AI 고지. 코드 작업은 반나절 규모다.

## 0. 요약

1. **골격은 Material 3 규격, 표면은 기존 지면 규칙을 따른다.**
   - M3 규격: 하단 바 64dp, 활성 표시자 56×32, small top app bar 64dp, 엣지 투 엣지.
   - 지면 규칙: 미색 용지, 먹 글자, 괘선, 모서리 0~4px, 주홍은 한 곳만.
   - 접점: M3의 알약 표시자는 **4px 사각 표시자**로 그린다.
2. **S1 첫 화면은 "진척 → 히어로 → 행" 순서다.**
   - 히어로: AI 코멘트 3줄 + "○○라면" 한 줄.
   - 행: 한 줄 소개 + '왜 지금' 1줄 + 메타.
   - 금액은 행 오른쪽 큰 숫자 열에서 빼고 메타 13px로 내린다.
   - 375×812 첫 실행 기준으로 히어로 + 행 2곳 + 3번째 행의 윗부분이 보인다.
   - IA가 목표로 한 "히어로 + 행 3곳"은 행 높이 때문에 그대로는 닿지 않는다. 조정안은 §3-8에 있다.
3. **'왜 지금'과 "○○라면"은 표지를 다르게 한다.**
   - '왜 지금'(편집 사실): 주홍 `trending-up` 아이콘.
   - "○○라면"(개인 관점): 먹색 사각 점 + 먹색 라벨.
   - AI 코멘트(해석): 회색 런인 라벨 + 왼쪽 먹선.
   - 세 줄이 붙어 있어도 서로 섞여 보이지 않는다.
4. **앱 아이콘은 A안(먹 바탕 + 미색 s + 인주 점)을 권장한다.**
   - 지금 아이콘을 계승해 108dp 3레이어로 다시 그렸다.
   - 점 색은 아이콘 전용 `#E5533A`다. 먹 바탕 위 대비가 4.72:1이다. UI 주홍 `#B7321C`는 2.92:1이라 24px에서 사라진다.
5. **위젯([1.1])은 브랜드 팔레트로 고정하고 동적 색은 쓰지 않는다.**
   - 스토어 스크린샷 6장은 템플릿 하나로 만든다: 기기 목업 없이 캡션 띠 360px + 실제 캡처 1560px.

## 1. 토큰

### 1-1. 값만 바뀌는 기존 토큰

| 토큰 | 기존 | 새 값 | 이유 |
|---|---|---|---|
| `--sd-header-h` | 52px (<1024) / 64px | **64px** (전 구간) | M3 small top app bar 64dp. 웹도 같은 값이라 분기가 없어진다 |
| `--sd-tabbar-h` | 56px | **64px** | M3 Expressive 내비게이션 바 64dp(A1, IA §5-2) |
| `--sd-tap` | 44px | **48px** | Android 터치 대상 48dp |
| `--sd-sticky-top` | `calc(var(--sd-header-h) + env(safe-area-inset-top))` | `calc(var(--sd-header-h) + var(--sd-inset-top))` | §1-4 |
| manifest `background_color` | `#1B1A17` | **`#F3EFE6`** | `theme_color`와 톤을 맞춘다(A3). 다크 스플래시는 네이티브 `values-night`가 맡는다 |

### 1-2. 새 색 토큰

| 토큰 | 라이트 | 다크 | 용도 | 대비(이 면 위 전경, 라이트 / 다크) |
|---|---|---|---|---|
| `--sd-surface-lift` | `#ECE7DC` | `#1C1F25` | 떠오른 top app bar, 하단 내비게이션 바, 그 뒤의 시스템 바 영역 | ink 14.27 / 13.39 · ink-2 8.23 / 7.83 · ink-3 4.77 / 5.21 · accent 4.88 / 6.19 · line-ui 3.40 / 3.36 |
| `--sd-indicator` | `#DDD5C4` | `#2E333C` | 하단 바 활성 표시자 면 | ink 12.05 / 10.29 · ink-2 6.95 / 6.02. **ink-3·accent는 이 면에 쓰지 않는다**(4.03 / 4.00) |

- `--sd-surface-lift`와 `--sd-bg`의 차이는 1.07(라이트) / 1.13(다크)로 작다.
  - 그래서 떠오름을 면 색만으로 보여 주지 않는다. **`--sd-shadow-1`(1px `--sd-line` 하단 선)을 함께 켠다.**
- `--sd-indicator`는 장식이다.
  - 활성 상태는 아이콘 채움, 글자 색 ink, 700 굵기, `aria-current`로도 전달된다.
  - 그래서 면 대비 1.18이어도 WCAG 1.4.11에 걸리지 않는다.
- 아이콘 전용 상수 `#E5533A`(인주 점)는 CSS 토큰으로 만들지 않는다. 앱 아이콘·스플래시·위젯 글리프에만 쓴다.

### 1-4. 인셋 사용 규칙 (엣지 투 엣지, A3)

```css
:root {
  --sd-inset-top: var(--safe-area-inset-top, env(safe-area-inset-top, 0px));
  --sd-inset-right: var(--safe-area-inset-right, env(safe-area-inset-right, 0px));
  --sd-inset-bottom: var(--safe-area-inset-bottom, env(safe-area-inset-bottom, 0px));
  --sd-inset-left: var(--safe-area-inset-left, env(safe-area-inset-left, 0px));
}
```

1. **컴포넌트는 `env(safe-area-inset-*)`를 직접 부르지 않고 `--sd-inset-*`만 쓴다.**
   - 앱에서는 Capacitor 8.3.2+가 주입하는 `--safe-area-inset-*`가 먼저 쓰인다.
   - 웹에서는 `env()`로 대체된다.
   - 교체할 곳: `app.css` 218·271·272·296·299행, `tokens.css` 69행.
2. **인셋은 한 겹만 더한다.** 담당은 아래 표와 같고, 나머지 요소는 인셋을 더하지 않는다.

| 위치 | 담당 요소 | 규칙 |
|---|---|---|
| 위 | top app bar | `padding-top: var(--sd-inset-top)`. 배경을 상태 바 뒤까지 칠한다 |
| 위(app bar 없는 화면) | 풀스크린 시트 | 첫 블록 `padding-top: calc(16px + var(--sd-inset-top))` |
| 아래 | 하단 내비게이션 바 | `height: calc(var(--sd-tabbar-h) + var(--sd-inset-bottom)); padding-bottom: var(--sd-inset-bottom)` |
| 아래(바 없는 화면·시트) | 고정 하단 버튼 줄, 바텀시트 | `padding-bottom: var(--sd-sheet-pad-bottom)` |
| 본문 끝 | `.shell` | `padding-bottom: calc(var(--sd-tabbar-h) + var(--sd-inset-bottom) + 32px)` |
| 떠 있는 요소 | 스낵바 | `bottom: var(--sd-snack-bottom)` |
| 좌우 | 거터 | `padding-inline: max(var(--sd-gutter), var(--sd-inset-left))`(오른쪽도 같은 식) |

3. 키보드가 열린 검색 화면에서는 하단 바를 숨긴다(기존 규칙). 이때 고정 하단 요소는 `--sd-inset-bottom`만 더한다.

## 2. 앱 내비게이션 골격 [1.0]

### 2-1. 하단 내비게이션 바 (A1, IA §5-2)

```
┌───────────────────────────────────────────┐ ← 1px --sd-line
│   ┌──────┐                                │   위 패딩 12
│   │ ▤▤▤▤ │        ⌕            ⌑          │   표시자 56×32 (모서리 4), 아이콘 24
│   └──────┘                                │   간격 4
│   최신 호          탐색          저장        │   라벨 13px / 16 → 합계 64
│▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔│ ← --sd-inset-bottom (같은 배경)
└───────────────────────────────────────────┘
```

| 요소 | 스펙 |
|---|---|
| 컨테이너 | `position: fixed; inset-inline: 0; bottom: 0;`<br>높이 `calc(64px + var(--sd-inset-bottom))`<br>배경 `--sd-surface-lift`, 위 1px `--sd-line`. 블러·반투명 없음 |
| 탭 | 최신 호 / 탐색 / 저장, 3개 유지.<br>`flex: 1; display: flex; flex-direction: column; align-items: center; padding-top: 12px; gap: 4px;`<br>탭 전체가 터치 대상(375 기준 125×64) |
| 표시자 | 56×32, `border-radius: var(--sd-radius-2)`(4px), 배경 `--sd-indicator`.<br>IA는 "알약 인디케이터"라고 썼다. 크기와 위치는 M3를 따르고, 모양만 지면 규칙(알약 금지)에 맞춰 4px 사각으로 바꿨다 |
| 아이콘 | 24px.<br>비활성: 라인 아이콘 `--sd-ink-3`.<br>활성: 채운 변형 `--sd-ink`(`newspaper` 채움 / `search` stroke 2.25 / `bookmark` 채움).<br>저장 탭이 활성이어도 채움 색은 ink다. 주홍 채움은 "저장됨" 상태에만 쓴다 |
| 라벨 | 13px / 16px. 비활성 500 `--sd-ink-3`, 활성 700 `--sd-ink`.<br>M3 Expressive는 선택 라벨을 굵게 하지 않는다. 하지만 한글 13px는 색 차이만으로 구분이 약해서 굵기를 남긴다 |
| 눌림 | 표시자 자리에 56×32 사각이 120ms 동안 나타난다. 라이트 `--sd-surface-2`, 다크 `--sd-line`. 물결(ripple) 효과는 없다 |
| 전환 모션 | 표시자 `scaleX(.6 → 1)` + opacity, 200ms `--sd-ease-out`. reduced-motion이면 즉시 |
| 배지 | 6×6 `--sd-accent` 정사각 점. 아이콘 오른쪽 위(`top: -2px; right: -4px`), 표시자 면 밖에 둔다. 숫자 배지는 없다.<br>켜는 조건은 IA §5-2(최신 호 = 새 호, 저장 = 마지막으로 저장 탭을 연 뒤 새로 저장함) |
| 같은 탭 재탭 | IA §5-2 동작(맨 위로 → 루트). 시각 효과는 따로 없다 |
| 접근성 | `<nav aria-label="주 메뉴">`, 활성 탭 `aria-current="page"`. 점이 켜지면 라벨에 숨김 텍스트 "새 항목"을 붙인다 |
| 600dp 이상 | 아이콘과 라벨을 가로로 놓는다. 표시자 폭 = 좌우 16 + 아이콘 + 8 + 라벨. ≥1024는 기존 상단 내비 |

- **탭 위 2px 주홍 바(기존 활성 표시)는 없앤다.** 주홍 사용처가 하나 줄어든다(§11-1).

### 2-3. 화면별 변형 (IA §5-3)

**S1 최신 호 — large flexible, 스크롤하면 small로 접힘 (A2)**

│░░░░░░ 상태 바 (--sd-bg) ░░░░░░░░░░░░░░░│  │░░░░░░ 상태 바 (lift) ░░░░░░░░░░░░░░░░░░│

- **줄 1(64px, sticky)**
  - 왼쪽: 워드마크 18px 800 + 인주 점.
  - 오른쪽 3개, 모두 48px:
    - 정보 `info` → AI 고지·작성 방식 시트(IA §3-1의 "app bar 정보 아이콘")
    - 알림 벨 → C2 트리거 ③. 이미 허용했다면 S8 알림.

### 6-2. C3 상태 5종 (문구는 IA §5-6)

**① 로딩**
- 첫 실행: 시스템 스플래시 → 행 뼈대 4줄.
  - 뼈대 행: 로고 40 사각 + `--sd-surface-2` 막대 3줄(이름 40%×16, 소개 90%×12, 메타 60%×12). 행 높이 108.
  - 3초 뒤 뼈대 아래 가운데에 13px `--sd-ink-3` "오늘 호를 받아오는 중이에요". 8초 뒤 오류로 넘어간다.
- 뼈대 모션: opacity 1 ↔ .55, 1200ms. reduced-motion이면 정지.
- 300ms 미만으로 끝나면 뼈대를 그리지 않는다(02 §5-24).
- 분석 생성: 기존 3px 진행 막대(`.lens-ask__bar`) + 단계 문구 + 경과 초를 유지한다.
  - IA는 "물결형 진행 막대"를 썼다. 비주얼은 직선 3px로 둔다. 물결형은 계속 움직이는 장식 모션이라 02 §6 모션 원칙(장식 모션 금지)과 맞지 않는다.
  - 완료 스낵바: "분석이 준비됐어요 · 보기".

**② 오프라인 띠**

```
├───────────────────────────────────────────┤ app bar 아래
│ ⊘ 오프라인 · 받아 둔 호와 저장한 회사만 볼 수 있어요 │ 32px, --sd-ink 면, --sd-on-ink 글자 13/500
├───────────────────────────────────────────┤
```

- 위치: `position: sticky; top: var(--sd-sticky-top);` 전체 폭. 본문을 덮지 않고 밀어낸다.
  - S3에서는 섹션 칩 내비 위에 쌓인다. 칩 내비 `top`에 32px를 더한다.
- 색: 먹색 반전(15.33:1). 오류가 아니라 상태이므로 경고색을 쓰지 않는다.
- 내용: `wifi-off` 16px + 문구. 375에서 한 줄이 넘치면 "받아 둔 호와 저장한 회사만"까지만 보이게 말줄임한다.
- 진입: `translateY(-100% → 0)` 200ms. 다시 연결되면 사라진다. 닫기 버튼은 없다.
- 네트워크가 필요한 버튼(분석 생성, 외부 링크, 공유 이미지)
  - 비활성 표시: `--sd-ink-3` 글자, 테두리 `--sd-line`.
  - 버튼 아래 13px `--sd-ink-3`: "연결되면 쓸 수 있어요" / "Needs a connection".

**③ 빈 상태**
- 02 §5-23 구성을 그대로 쓴다: 아이콘 40(stroke 1.5, `--sd-ink-3`) → 제목 18px 700 → 설명 15px → 버튼.
- 문구와 버튼은 IA 표를 따른다.

| 경우 | 아이콘 | 버튼 |
|---|---|---|
| 저장 0 | `bookmark` | 보조 "오늘 호 보기" |
| 검색 0 | `search` | 분야 칩 3개(필터 칩 스타일) |
| 새 호 공백 | `calendar-days` | S1 공백 카드(§3-6 D)로 대신한다 |
| 첫 실행 오프라인 | `wifi-off` | 보조 "다시 시도" |

**④ 오류**
- **스낵바**(기존 `Toast`를 스낵바로 통일)
  - 배경 `--sd-ink`, 글자 `--sd-on-ink` 15px 500, 모서리 4, min-height 48, 패딩 `12px 16px`.
  - 좌우는 거터만큼 띄우고, 아래는 `--sd-snack-bottom`.
  - 액션 1개: 15px 700 + 1.5px 밑줄 `--sd-accent`.
  - 액션이 있으면 사라지지 않고 탭이나 스와이프할 때까지 남는다. 없으면 4초 뒤 사라진다.
- 상세 전체 레코드 실패: S3 본문 맨 위에 `--sd-warning-soft` 면 + `--sd-warning` 글자 15px 띠(패딩 12 16) + 보조 버튼 "다시 시도". 그 아래에 목록 정보를 보여 준다.
- 화면이 통째로 비는 오류는 빈 상태 형식으로 그린다: `circle-alert` + IA 문구 + "다시 시도" + 13px 모노 오류 코드(제보용).

**⑤ 업데이트**

| 종류 | 표시 |
|---|---|
| 새 호(앱 실행 중) | 스낵바 "새 호가 나왔어요" + 액션 "보기" → S1 맨 위로 + 갱신. 분석 생성 중에는 미룬다 |

## 9. 앱 아이콘 [1.0]

### 9-1. 권장: A안 — 먹 바탕 + 미색 s + 인주 점

| 레이어 | 내용 | 파일 |
|---|---|---|
| 배경 | 108×108dp 단색 `#1A1915`(= 라이트 `--sd-ink`) | `icon-a_background.svg` |
| 전경 | 소문자 s 한 획(stroke 10dp, 끝 각지게) `#F3EFE6`(= `--sd-bg`) + 9×9dp 정사각 인주 점 `#E5533A`.<br>글리프 외곽 약 44×51dp, 가운데 66dp 원 안(점 모서리까지 중심 거리 30dp < 33) | `icon-a_foreground.svg` |
| 모노크롬 | 전경과 같은 모양, 단색(알파만 쓰인다). 점도 같은 색으로 남아 모양으로 식별된다 | `icon-a_monochrome.svg` |
| Play 512 | 같은 구성을 78dp 창(`viewBox 15 15 78 78`)으로 잘라 512×512 풀블리드로. 모서리는 Play가 자른다.<br>32비트 PNG, 1MB 이하, 글자·배지 없음 | `icon-a_play-512.svg` |

- **A안을 고른 이유**
  - 지금 `icon-512.png`(먹 바탕 + s + 주홍 점)와 인상이 같다. 웹 PWA를 설치한 사람의 홈 화면 아이콘과 이어진다.
  - 워드마크의 "글자 + 인주 사각 점"을 그대로 줄인 형태다. 24px에서도 s와 점이 보인다.
  - 미색 Play 페이지와 대부분의 배경화면 위에서 대비가 크다.
- **점 색 `#E5533A`**
  - UI 주홍 `#B7321C`는 먹 바탕 위 2.92:1이라 런처 크기에서 묻힌다.
  - 다크 주홍 `#FF7452`(6.59:1)는 주황으로 읽힌다.
  - 그 사이 값으로 4.72:1을 확보했다. **아이콘·스플래시·위젯 글리프 전용이며 UI 토큰으로 쓰지 않는다.**
- 글리프는 폰트가 아니라 path로 그렸다. SVG의 서체 대체로 모양이 바뀌는 것을 막기 위해서다. Android Studio Vector Asset으로 그대로 가져올 수 있다.

### 9-2. 대안: B안 — 미색 바탕 + 인주 도장 안에 s

- 46dp 인주(`#B7321C`) 사각 도장에서 미색 s를 파낸 형태다. 파일: `icon-b_*.svg`.
- 쓰는 경우: 뉴스 앱 아이콘에 검은 바탕이 많아 A안이 묻힌다고 판단될 때.
- 채택하지 않은 이유:
  1. 밝은 배경화면과 Play 흰 페이지에서 바탕이 사라지고 빨간 사각만 남는다.
  2. 주홍 면이 커서 "액센트는 점 하나" 원칙과 어긋난다.
  3. 테마 아이콘에서 단색 사각 덩어리가 되어 A안보다 식별성이 낮다.

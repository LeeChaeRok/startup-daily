## 1. 제품 정의

**한 줄 정의:** 매일 아침, 아직 덜 알려졌지만 지금 뜨는 스타트업 5곳을 "왜 지금"과 함께 한국어로 5분 안에 읽게 해 주는 앱.

**첫 화면이 답해야 할 질문 (스크롤 없이, 375×667 기준)**
1. 이건 뭐 하는 곳인가? → 첫 방문 한정 안내 한 줄 + 날짜 헤더.
2. 오늘 것은 무엇이고, 얼마나 걸리나? → "11월 14일 금요일 · 5곳 · 요약만 약 5분".
3. 첫 회사는 무엇이고 왜 오늘인가? → 1번 카드가 첫 화면 안에 통째로 보인다(로고·이름·한 줄·왜 지금·숫자).

답하지 않는 질문(다른 화면으로 보냄): 호 번호, 진행률, YC 전체 목록, 공모전, 지난 날 목록, AI 고지 문단.

| 분량 줄 | 5곳 각각 1층 글자 수(`tagline`+`trending_reason.summary`+팩트) ÷ 500자/분, 반올림, 최소 1분 | 읽는 중: "n곳 남음 · 약 m분". "0/5"·진행 막대 없음 |

| 읽은 카드 | 순번 · ✓ · `name_ko` · `tagline` 1줄 | 한 줄로 접히고 흐려짐. 순서는 그대로(위치가 바뀌면 길을 잃음) |
| 완료 카드 | "오늘 다섯 곳 끝. 내일 아침 새 다섯 곳이 와요." + 제안 1개 + "오늘 5곳 공유" 텍스트 버튼 | 5곳 모두 읽음일 때만. 제안은 하루 1개, 순서: ① 알림(지원 기기·미설정·방문 2일째 이상) ② 관심 분야(미설정) ③ 없음 |
| 어제 놓친 곳 | 전날 공개 5곳 중 안 읽은 곳 수 + 로고 겹침 3개 | "어제 놓친 2곳 →" 한 줄 → `#/d/어제`. 0곳이면 숨김 |
| YC 새 배치 | `ycOf(date)` 개수, 배치명(`yc.batch` → "Summer·Fall 2026"), 로고 겹침 3개 | "YC 새 배치 · 오늘 10곳 →" 한 줄 → `#/yc/:date`. 그날 YC 없으면 숨김 |
| 그때 그 회사 | `followUps(2)`: `updates.json`의 `kind` 라벨 · `title_ko` · 회사명 · `date` | 최근 14일 안 소식이 있을 때만, 2줄 행 최대 2개 → 상세(맨 위 "새 소식" 띠 펼침) |
| 내 분야에서 더 | `moreInMySectors()` (`pick.js`) | 관심 분야를 고른 사람만, 2줄 행 최대 3개. 분야 풀 공개 정책은 질문 2 |
| 바닥 한 줄 | `stats.issues`(발행 일수) | 소개(`#/about`)·English(언어 전환) 링크 |

하단 블록 우선순위: 완료 카드 > 어제 놓친 곳 > YC > 그때 그 회사 > 내 분야. **완료 카드를 빼고 최대 3개**만 보인다. 끝이 보이는 하루(P3)를 지키기 위해서다.

**상태**

| 상태 | 화면 |
|---|---|
| 로딩 | 날짜 헤더 자리 + 카드 모양 스켈레톤 5개(실제 높이와 같게) |
| 첫 방문 | 안내 한 줄 표시. 시트·모달 없음 |
| 일부 읽음 | 읽은 카드 접힘, 분량 줄이 "n곳 남음" |
| 모두 읽음 | 다섯 줄로 접힌 목록 + 완료 카드 |
| 새 발행 도착(앱 켜 둔 채) | 하단 토스트 "새 다섯 곳이 도착했어요 · 보기"(`watchForUpdates` 재사용) |
| 오프라인 | 상단 얇은 띠 "오프라인 · 저장된 화면을 보여드려요". 캐시된 최신 날짜 표시 |
| 데이터 로드 실패 | "불러오지 못했어요 · 다시 시도" 버튼 하나 |
| 지난 날(`#/d/:date`) | 헤더 "11월 12일 수요일 · 지난 날" + 오른쪽 "오늘로" 칩. 하단 블록은 YC만(그날 YC가 있으면) |

**행동:** 주 = 카드 탭(상세). 보조 = 날짜 시트, YC 진입, 공유(완료 카드).

**날짜 시트(바텀 시트)**: 최근 14일 행 "11월 13일 목 · 5곳 · ✓ 다 읽음 / 2곳 읽음 / 안 봄"(`useReadLog`, `useSeen('issue')`) + 맨 아래 "전체 날짜 보기 →"(`#/explore?view=dates`).

**데스크톱 ≥1024px:** 가운데 한 단 720px. 카드 5장은 같은 형식, 카드 폭이 넓으므로 tagline·왜 지금이 1줄씩으로 줄어 카드가 더 낮아진다. 하단 블록은 같은 순서. 오른쪽 레일·숫자 스트립 없음.

**지금 대비 없앤 것:** "제37호" 제목, "0/5"·진행 막대, 히어로 상자, 같은 화면의 YC 행 목록, 취향 카드, 지난주 카드, 지난 호 목록, "이 호의 숫자", "이 호의 분야", "이 호 공유" 카드, 이전/다음 호 버튼, "내 관심 순/발행 순" 전환, "내 5곳 | 모두의 5곳" 전환, AI 고지·데이터 범위 문단.

### 3-3. YC (`#/yc/:date`)

**목적:** 그날 YC 새 배치 회사를 한눈에 훑는다.

**모바일**
```
[‹ 오늘]                                   
YC 새 배치
‹ 11.13     11월 14일 금요일     11.15 ›      ← 이전/다음 YC 날짜(ycDates)
Summer 2026 · Fall 2026 배치에서 10곳
──────────────────────────────
2줄 행 × 최대 10 (배지 S26/F26, 오른쪽 값 = 단계)
──────────────────────────────
YC 회사는 오늘의 다섯 곳과 겹치지 않아요. 모든 YC 회사 보기 → (#/explore?yc=1)
```
- 데이터: `ycOf(date)`, `yc.batch`, 행 공통 필드.
- **기본 5곳 + 더 보기 → 전부 표시(최대 10)**. 2줄 행 10개는 한 화면 반 정도라 접을 이유가 없다.
- 상태: 그날 YC 없음 → "이날은 YC 새 회사가 없어요" + 가장 가까운 YC 날짜 버튼. 로딩 = 행 스켈레톤.
- 하단 탭 표시, 활성 탭 = 오늘.
- 데스크톱: 가운데 720px 같은 목록. 회사를 누르면 상세(레일 = 그날 YC 목록).
- **없앤 것:** 하단 YC 탭, "0/5" 진행 막대, 오늘 화면 안의 YC 행 목록.

### 3-4. 탐색 (`#/explore`)

**목적:** 지난 회사 전체에서 찾기(검색·필터)와 둘러보기(묶음). 첫 결과가 화면 상단 1/3 안에 와야 한다(M §6).

**모바일 375px**
```
[로고]                                   [⚙]
┌ 🔍 회사·분야·투자사 검색 ─────────────┐        ← 상단 바 아래 고정
[필터 2] [AI] [헬스] [핀테크] [YC] [안 읽은 것] →   ← 칩 1줄 가로 스크롤
──────────────────────────────
(검색·필터 없음 = 둘러보기)
  분야별                                       ← 2열 그리드 카드: 분야명 · n곳 · 로고 겹침 3
  날짜별                                       ← 최근 날짜 2줄 행 7개 + "전체 날짜" (= view=dates)
  YC                                          ← "YC 회사 n곳 모두 보기" 한 줄
(검색·필터 있음 = 결과)
  128곳 · 최신순 ▾
  2줄 행 목록 (무한 스크롤 아님, 30개씩 "더 보기")
```
- 검색 범위: 공개 회사(`featured` 5곳 + YC). 비공개 풀 제외. `search(query)` 그대로(이름·tagline·분야·투자사).
- 칩: 분야 상위 3개(그 사람 관심 분야가 있으면 그것 먼저) + YC + 안 읽은 것. 칩 맨 앞 "필터 n"이 필터 시트를 연다.
- **필터 시트:** 분야(`SECTORS`), 단계(`STAGE_GROUPS`), 지역(`REGIONS`), 한국 시장(`LENS_FILTER`, 한국어판만), 정렬(최신순·누적 투자 큰 순). 하단 버튼 "128곳 보기"(실시간 개수, P11), "초기화".
- `view=dates`(날짜별 전체): 날짜 2줄 행 "11월 13일 목 · 5곳 · YC 10곳 · ✓ 다 읽음" → `#/d/:date`.
- 상태: 결과 0 → "조건에 맞는 회사가 없어요" + 마지막에 건 필터 하나를 빼는 버튼("'Series C' 빼고 보기"). 검색 중 입력 지연 200ms. 오프라인 = 캐시된 날짜 범위 안에서만 검색됨 표시.
- 데스크톱: 상단 바 검색창과 같은 상태 공유. 가운데 960px, 결과는 2열 2줄 행 그리드. 필터는 시트 대신 "필터" 버튼 아래 팝오버 패널.
- **없앤 것:** "회사/지난 호" 세그먼트, 검색·전환·칩·필터 버튼·결과 수가 다섯 줄로 쌓인 머리(m-05), 4~5줄 행, 데스크톱 표(d-03), 분야 모아 보기 별도 화면(`#/t/`), "숨긴 분야 보기" 토글.

### 3-7. 저장 (`#/saved`)

**목적:** 저장한 것을 다시 찾고, 공모전 마감을 놓치지 않는다.

```
[로고]                                   [⚙]
저장
( 회사 12 | 공모전 3 )                    ← 둥근 세그먼트 1개
── 회사 탭 ──
새 소식 있는 회사 먼저 (● 표시)
2줄 행 × n  (저장한 순, 최근이 위)  · 정렬 ▾ (저장 순 / 소개된 날짜 순)
최근 읽은 회사                     ⌄    ← 접힘, 최근 20곳 (useReadLog 날짜순)
── 공모전 탭 ──
마감 순 2줄 행(D-day 칩)
마감된 공모전 (1)                  ⌄    ← 접힘
```
- 데이터: 저장 store(회사 id), `useSavedContests()`, `updates`(새 소식 점), `useReadLog`.
- 상태: 빈 회사 → "회사 상세에서 🔖를 누르면 여기에 모여요" + "오늘의 5곳 보기" 버튼. 빈 공모전 → "공모전 둘러보기" 버튼. 빈 상태 아래 작은 글씨로 "이 기기에만 저장돼요".
- 행 왼쪽으로 밀어 삭제는 하지 않는다(실수 위험). 저장 해제는 상세에서, 또는 길게 눌러 메뉴 "저장 해제" + 되돌리기 토스트.
- 데스크톱: 가운데 720px 같은 구조. 회사를 누르면 상세(레일 = 저장 목록).
- **없앤 것:** 상단 바 북마크 아이콘·숫자 배지(m-08), 각진 세그먼트, 항상 보이던 "이 기기의 브라우저에만 저장돼요" 안내(→ 빈 상태와 설정), "안 읽은 것만" 토글(저장 목록에서는 쓰임이 적다; 탐색 칩으로 대체).

### 3-8. 설정 (`#/settings`) · 소개 (`#/about`)

**설정 — 위→아래**
1. **나에게 맞추기:** 역할(`ROLES`, 하나 또는 없음) · 관심 분야(`SECTORS` 다중).
2. **알림:** 새 다섯 곳 알림 켜기/끄기(`AlertSetting`, 지원 안 되는 브라우저는 "홈 화면에 추가하면 켤 수 있어요" 안내).
3. **화면:** 언어(한국어/English) · 테마(시스템/라이트/다크) · 글자 크기(작게/기본/크게).
4. **내 기록:** "저장과 읽은 기록은 이 기기에만 있어요" 설명 · 저장 내보내기 · 읽은 기록 지우기(확인 시트).
5. **정보:** 소개·선정 기준 · 만드는 법(사용 모델명은 여기에만, M §5) · 정정 기록 · 틀린 내용 알리기 안내 · 버전.

- **없앤 것:** "호 안의 순서(내 관심 순/발행 순)", 분야 숨기기(§6 참고).
- 데스크톱: 가운데 640px 같은 구조.

**소개:** 무엇을 하는가(제품 한 줄) → 어떻게 고르는가(선정 기준) → 어떻게 만드는가(AI 조사·확인 절차·모델) → 정정 기록 → 운영자. 지금의 `?sec=` 앵커 유지.

## 4. 핵심 플로우

### 4-1. 첫 방문 (막는 모달 없음)

```
링크/검색으로 #/ 진입
 → 오늘 화면 바로 표시 + 안내 한 줄 ("매일 아침, 아직 덜 알려진 스타트업 5곳을…")
 → 카드 1 탭 → 상세 1층을 읽음(왜 지금 2초 노출 = 읽음, 안내 줄 영구 해제)
 → 1층 "내 입장에서" 줄에 역할 칩 4개 ── 고르면 즉시 그 회사의 한 줄 표시 / ×면 다시 안 물음
 → "다음 →"로 2~5번
 → 5곳 다 읽으면 완료 카드
      · 방문 2일째 이상 & 알림 미설정 & 지원 기기 → "내일 아침에 알려드릴까요? [켜기]"
      · 그 외 & 관심 분야 미설정 → "관심 분야를 고르면 그 분야 회사를 더 보여 드려요 [고르기]" (분야 칩 시트)
```
- 묻는 시점의 원칙: **가치를 본 직후, 그 가치와 연결된 질문 하나만**(P14). 역할은 "내 입장에서 한 줄"이 보이는 바로 그 자리에서, 관심 분야는 "더 보고 싶다"가 생기는 완료 시점에서, 알림은 "내일도 오겠다"가 생기는 둘째 날 완료 시점에서.
- 공유 링크(`/s/:id`)로 처음 온 사람: 상세가 먼저 열리고, 상단 바 [‹]는 오늘 화면으로 간다(뒤로 갈 앱 내 기록이 없을 때, 지금 `isColdStart` 로직). 상세 맨 아래 "다음" 대신 "오늘의 5곳 보기 →".

### 4-2. 매일 습관 루프 (열기 → 5곳 → 끝)

```
아침 푸시 "오늘의 5곳: 데이라이트 시큐리티 외 4곳" (켠 사람만, 하루 1회)
 → 오늘 화면: "5곳 · 요약만 약 5분"
 → 카드 1 → 상세 1층(30초~1분) → 다음 → … → 5번 → "오늘 끝 →"
 → 오늘 화면: 다섯 줄 접힘 + 완료 카드 "오늘 다섯 곳 끝"
 → (선택) 어제 놓친 곳 / YC / 그때 그 회사
```
- 진행은 숫자 숙제가 아니라 상태 변화로 보인다(카드 접힘, "n곳 남음"). 스트릭 숫자·불꽃 없음(M §6, P4).
- 중간에 나갔다 다시 오면: 읽은 카드는 접혀 있고 첫 안 읽은 카드가 화면 위쪽에 온다(스크롤 위치 자동 이동은 하지 않음, 접힘만으로 충분).

### 4-3. 저장하고 다시 찾기

```
상세 하단 🔖 → 아이콘 채움 + 토스트 "저장했어요 · 되돌리기"(4초)
 → 저장 탭(회사)에서 최근 순으로
 → 그 회사에 새 소식(updates.json) 생기면: 저장 탭 아이콘 점 + 행 앞 ● + 상세 맨 위 "새 소식" 띠
 → 저장하지 않았어도 읽은 회사는 저장 탭 "최근 읽은 회사"에서 다시 찾음
 → 그 밖엔 탐색 검색
```

### 4-4. 공모전 마감 추적

```
공모전 탭 → 칩/필터로 좁힘 → 행의 🔖 (또는 상세에서 저장)
 → 공모전 탭 상단에 "저장한 공모전 n건 · 가장 빠른 마감 D-1" 줄
 → 저장 탭(공모전): 마감 순, D-day 칩. 마감 지나면 "마감된 공모전"으로 접힘
 → 상세 "캘린더에 추가"(.ics) — 실제 알림은 사용자 캘린더가 담당
 → (Later) 저장한 공모전 D-3 푸시
```

## 5. 회사 프로필 구조 (점진적 공개)

### 5-1. 두 층

| 층 | 들어가는 것 | 목표 |
|---|---|---|
| **1층 (첫 화면 + 한 번 스크롤 안)** | 정체성 → 한 줄 → 메타 → 팩트 3칸 → 왜 지금 → 내 입장에서 → 신뢰 한 줄 | 30초~1분에 완결. 글자 수 목표 600자 이내(M §4-2, 추정치 — QA에서 실제 레코드로 확인). 375×667에서 "왜 지금" 첫 2줄까지 스크롤 없이 보임 |
| **2층 (접힌 섹션 7개)** | 제품 · 경쟁 · 팀 · 투자 · 시장 · 한국에서는 · 출처 | 원하는 섹션만 연다. 섹션마다 제목 + 2줄 미리보기 |

### 5-2. 2층 섹션 명세 (모든 섹션이 같은 형식: 제목 / 미리보기 2줄 / 펼친 본문)

| 섹션 | 미리보기(접힌 상태) | 펼친 본문(순서) |
|---|---|---|
| 제품 | `product.summary` 첫 문장 | `summary` → 문제(`problem_statement`) → 해법(`solution`) → 핵심 기능(`key_features[]` 불릿) → 기술(`tech_stack_or_innovation`) → 고객(`target_customer`) → 수익 모델(`business_model`) → 키워드(`category[]` 작은 칩) |
| 경쟁 | `competitive_landscape.key_differentiator` 첫 문장 | 차별점(`key_differentiator`) → 경쟁사(`direct_competitors[]`: 이름 굵게 + `comparison`, 행 리스트) → 해자(`moat`) → 정리(`competitive_position_summary`) |
| 팀 | "창업자 n명 · 직원 `employee_count`" | 창업자 카드(`founders[]`: `name_ko`/`name_en`, `role`, `background`, `notable_achievement`) → `team_highlights` |
| 투자 | "라운드 n회 · 리드 `latest_round.lead_investor`" | 세로 타임라인(`latest_round` + `funding_history[]`, 날짜 내림차순: 날짜·단계·금액·리드·`note`) → 주요 투자자(`notable_investors[]`) → 누적(`total_raised` + `total_raised_note`) → 기업가치(`valuation_estimate`, 추정 꼬리표). 차트 없음(P9) |
| 시장 | `market_outlook.tam_sam_som` 첫 문장 | 시장 규모(`tam_sam_som`) → 흐름(`market_trend`) → 성장 여지(`growth_potential`) → 위험(`risks[]` 불릿) → 대응(`risk_mitigation`) → **에디터 한 줄**(`editor_pick_comment`, "AI 작성" 꼬리표) |
| 한국에서는 | 판정 배지(`LENS_VERDICTS[verdict].label`) + `headline` | `headline` → 비슷한 곳(`similar[]`: 이름·`country_ko`·`relation`·`summary`·링크, `verified`) → "검색 기반 가설이에요" 한 줄. 없으면 생성 버튼(§3-2 상태) |
| 출처 | "링크 n개 · 모두 확인됨 / n개 확인 안 됨" | 언론 보도(`media_mentions[]`: 매체·날짜·제목·링크·✓) → 관련 링크(`related_links[]`: 제목·링크·✓) → 웹사이트 확인(`website_check`) → "AI가 {generated_at 날짜}에 공개 자료로 정리" → 틀린 내용 알리기 · 정정 기록 |

- `verified !== true` 링크는 체크 없이 회색 "확인 안 됨" 꼬리표. 숨기지 않는다(정직, P19).
- 섹션 펼침 상태는 회사 간에 기억한다(제품을 늘 펼치는 사람은 다음 회사에서도 펼쳐져 있음). 기기 저장.

### 5-3. 섹션 이동

- 모바일: 상단 바 가운데 "회사명 · 현재 섹션 ▾" → **목차 시트**. 항목 누르면 그 섹션이 펼쳐지며 스크롤. "모두 펼치기 / 모두 접기" 토글.
- 가로 칩 줄은 쓰지 않는다(375px에서 절반이 잘림, A 7번).
- 데스크톱: 섹션 전부 펼침으로 시작, 상단 바 목차는 같음. 키보드: `j/k` 다음·이전 회사(맥락 목록), `s` 저장(Later로 둬도 됨).
- 읽기 진행선(2px)은 상단 바 아래. 1층 끝에서 약 30%가 되도록 문서 전체 기준이 아니라 "펼친 내용 기준"으로 계산.

### 5-4. "읽음" 판정

- **자동만.** "왜 지금" 블록이 화면(뷰포트 85% 위)에 탭이 보이는 상태로 **2초 이상** 있으면 읽음(`useReadTracking`을 이 블록에 연결). 1층을 읽었다 = 이 서비스의 약속(요약 5분)을 지켰다는 뜻이므로 2층까지 요구하지 않는다.
- 수동 "읽음" 버튼 삭제. 되돌리기는 ··· 메뉴 "안 읽음으로 표시"(`setRead(ids,false)`, `keptUnread`로 다시 자동 표시되지 않게).
- 읽음 기록은 오늘 카드 접힘, 2줄 행 체크, 날짜 시트 "다 읽음", 완료 카드, 어제 놓친 곳 계산에 쓴다.

## 8. 사장님께 묻는 것 (5개)

1. **다섯 곳의 무게:** 다섯 곳을 같은 형식 카드로 통일하고 "1번 = 오늘의 대표"를 따로 강조하지 않기로 했습니다. 1번을 꼭 크게 보여 줘야 할 편집 의도가 있나요?
2. **분야 풀 노출:** 지금 "내 5곳"은 비공개 풀 회사를 보여 줍니다. v2의 "내 분야에서 더"(관심 분야를 고른 사람에게 최대 3곳)에서도 풀 회사를 보여 줘도 되나요, 아니면 공개 전까지 이 블록을 빼야 하나요?
3. **기능 삭제 동의:** 분야 숨기기, 주간 정리 화면, 호 안 순서 전환, "내 5곳/모두의 5곳" 전환을 없애려 합니다. 이 중 꼭 남겨야 할 것이 있나요?
4. **영어판의 공모전:** 공모전은 국내 대상이라 영어판에서는 탭을 숨기는 편이 깔끔합니다(탭 3개). 숨겨도 될까요?
5. **발행 시각 약속:** 안내 문구와 푸시에 "매일 아침 ○시"처럼 시각을 적으면 습관에 좋습니다(지금 생성은 대략 오전 10시 전후). 약속할 시각이 있나요, 아니면 "매일 아침"으로 둘까요?

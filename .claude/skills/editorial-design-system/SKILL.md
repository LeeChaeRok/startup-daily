# Editorial Design System

## 방향
- **에디토리얼 + 데이터**: 신문/잡지의 위계(큰 헤드라인, 좁은 본문 폭, 룰 라인)와 데이터 카드(펀딩 숫자, 타임라인)를 결합한다. SaaS 대시보드나 보라 그라디언트 템플릿처럼 보이지 않게 한다.
- **한 가지 강한 액센트 + 중립 팔레트**. 카테고리 색 남발 대신, 카테고리는 텍스트 라벨/작은 도트로 구분한다 — 데이터의 카테고리가 180개 이상 자유 텍스트라 색 매핑이 불가능하기 때문이다.

## 산출물에 반드시 포함
1. **컬러 토큰 표**: 이름 | 라이트 | 다크 | 용도 | 대비비. 최소: bg, surface, surface-2, ink(텍스트) 3단계, line 2단계, accent, accent-ink, positive, warning.
2. **타이포**: 한글 본문 폰트(Pretendard 등 CDN 가능 폰트), 디스플레이 폰트(세리프/그로테스크 중 선택과 이유), 숫자용 tabular 설정. 스케일(px)·행간·자간 표. 본문 한 줄 최대 폭(예: 34~40em 한글 기준).
3. **간격/반경/그림자 스케일**.
4. **컴포넌트 스펙**: 헤더, 날짜 내비, 오늘의 이슈 카드(리드/일반), 기업 상세(히어로·섹션·펀딩 타임라인·경쟁 비교·팀), 칩/태그, 저장 버튼, 빈 상태, 하단 탭바(모바일). 각 컴포넌트의 상태(hover/active/focus/disabled).
5. **모션 원칙**: 지속시간·이징, prefers-reduced-motion 대응.
6. **아이콘**: 이모지 대신 일관된 라인 아이콘(인라인 SVG) 사용 규칙.
7. **로고 폴백**: 로고 이미지 실패 시 모노그램 규칙(배경색 해시 등).

## 검증
- 본문 텍스트 대비 4.5:1, 큰 텍스트 3:1 이상.
- 터치 타깃 44px 이상.
- 다크모드에서 순흑(#000) 대신 약간 띄운 배경 사용.
